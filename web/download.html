IPA-Palette
Version {{VERSION}} · kostenlos

Lautschrift per Klick – in jedem Programm.

Alle Zeichen des Internationalen Phonetischen Alphabets in einem schwebenden Fenster. Ein Klick tippt das Symbol dort ein, wo der Cursor steht: in Word, Pages, LibreOffice, im Browser oder in der E-Mail.

Für Windows herunterladenWindows 10 und 11 · {{MB_WIN}} MB Für Mac herunterladenmacOS 13 oder neuer · {{MB_MAC}} MB

Ohne Installation, z. B. unter Linux oder am Tablet: Palette im Browser öffnen (Klick kopiert das Zeichen).

Was sie kann

Alle IPA-Zeichen

Konsonanten, Vokaltrapez, Diakritika und Suprasegmentalia nach der offiziellen Tabelle.

Suche und X-SAMPA

Nach Name, Symbol oder Code suchen. "hal@ wird zu ˈhalə.

Klammern um Markiertes

Wort markieren, [ ], / / oder ⟨ ⟩ klicken – fertig.

Immer zur Hand

Schwebt über allen Fenstern, Strg+Alt+I bzw. ⌃⌥I blendet sie ein und aus.

Aktualisiert sich selbst

Neue Versionen meldet die App von selbst und installiert sie auf Klick.

Ohne Konto, ohne Werbung

Funktioniert offline und sammelt keine Daten.

So installieren Sie die Palette

Windows

  1. IPA-Palette-Setup.exe herunterladen und öffnen. Administratorrechte braucht es nicht.
  2. Hält der Browser die Datei zurück („wird nicht häufig heruntergeladen“, Datei hat 0 KB): in der Download-Liste des Browsers Download erlauben bzw. Behalten wählen.
  3. Fragt Windows „Der Computer wurde durch Windows geschützt“: Weitere Informationen → Trotzdem ausführen.
  4. Setup durchklicken, danach im Startmenü IPA-Palette öffnen.

Im S-Modus erlaubt Windows nur Apps aus dem Microsoft Store, auf Firmen- und Schulgeräten entscheidet oft die IT. Bis die Palette im Store ist, hilft dort die Browser-Palette.

Mac

  1. IPA-Palette.dmg herunterladen und öffnen.
  2. Die App auf „Programme“ ziehen und dort starten.
  3. Beim ersten Start Bedienungshilfen erlauben: Systemeinstellungen → Datenschutz & Sicherheit → Bedienungshilfen → IPA-Palette einschalten.

Signiert und von Apple geprüft. Das ə in der Menüleiste öffnet das Menü.

Merksatz: Diakritika immer nach dem Buchstaben klicken – sie setzen sich auf das Zeichen davor: erst b, dann ◌̥ ergibt b̥.
