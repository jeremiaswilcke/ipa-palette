IPA-Palette

Ein Add-in für Microsoft Word. Es öffnet neben dem Dokument eine Seitenleiste mit den Zeichen des Internationalen Phonetischen Alphabets: Ein Klick fügt das Symbol an der Cursorposition ein. Dazu gibt es eine Suche, eine X-SAMPA-Schnelleingabe, Klammern für phonetische, phonemische und graphemische Notation sowie eine Liste der zuletzt verwendeten Zeichen.

Im Browser ausprobieren Im Browser kopiert ein Klick das Symbol in die Zwischenablage.

1Dateien bei GitHub Pages veröffentlichen

Word lädt die Seitenleiste von einer https-Adresse. GitHub Pages stellt diese kostenlos bereit; es werden nur statische Dateien benötigt.

  1. Bei GitHub anmelden und ein neues öffentliches Repository mit dem Namen ipa-palette anlegen.
  2. Im Repository Add file → Upload files wählen und alle Dateien des Ordners ipa-palette hochladen, einschließlich der Unterordner assets und fonts (die Ordner lassen sich per Drag-and-drop in das Browserfenster ziehen). Anschließend Commit changes.
  3. Settings → Pages → „Deploy from a branch“ wählen, Branch main, Ordner / (root), dann Save.
  4. Nach etwa einer Minute diese Adresse öffnen: https://BENUTZERNAME.github.io/ipa-palette/ Dort erscheint diese Seite; mit ihr geht es bei Schritt 2 weiter.

2manifest.xml erzeugen

Die Manifest-Datei sagt Word, wo die Seitenleiste liegt. Sie wird hier im Browser für genau die Adresse dieser Seite erzeugt; es wird nichts hochgeladen.

Diese Seite wird nicht über https geöffnet. Ein Manifest, das auf diese Adresse zeigt, funktioniert in Word nicht. Bitte zuerst Schritt 1 abschließen und die Seite über die GitHub-Pages-Adresse öffnen.

Word für Windows (Kurzhinweis)

      
Unter Windows wird die manifest.xml über einen freigegebenen Netzwerkordner eingebunden: Ordner freigeben, in Word unter Datei → Optionen → Trust Center → Einstellungen für das Trust Center → Kataloge vertrauenswürdiger Add-Ins den Netzwerkpfad eintragen, Word neu starten und das Add-in unter Einfügen → Meine Add-Ins → Freigegebener Ordner wählen.


      
Updates

      
Word speichert die Seiten des Add-ins zwischen. Nach Änderungen am Add-in (neue Dateien auf GitHub) den Cache leeren, also den Inhalt dieses Ordners löschen und Word neu starten:
        ~/Library/Containers/com.Microsoft.OsfWebHost/Data/

    


    

      
4Schrift-Tipp

      
Für die schönste Darstellung in Word empfiehlt sich Charis SIL oder Doulos SIL, beide gratis bei SIL erhältlich:
        software.sil.org/charis und
        software.sil.org/doulos.
        Nach der Installation lässt sich die Schrift in der IPA-Palette unter Schriftart auswählen; sie wird dann auf alle eingefügten Zeichen angewendet. Mit der Voreinstellung „Dokumentschrift beibehalten“ bleibt die Schrift des Dokuments unverändert.
